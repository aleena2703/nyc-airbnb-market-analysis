# NYC Airbnb Market Analysis

## Project Overview

This project analyzes the New York City Airbnb market using Python-based Exploratory Data Analysis (EDA).

The analysis focuses on pricing trends, room type behavior, borough-level differences, and customer engagement patterns to uncover valuable business insights from Airbnb listing data.

---

## Business Objectives

* Analyze Airbnb pricing trends across NYC boroughs
* Compare pricing across different room types
* Identify premium neighborhoods in NYC
* Understand review behavior and listing popularity
* Detect and handle price outliers for accurate analysis

---

## Dataset Information

* Dataset: NYC Airbnb 2024 Dataset
* Format: CSV
* Rows: 20,000+ listings
* Features include:

  * Price
  * Borough
  * Room Type
  * Reviews
  * Availability
  * Neighborhood Information

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Data Cleaning & Preprocessing

The following preprocessing steps were performed:

* Removed missing values
* Handled duplicate records
* Removed price outliers
* Performed feature engineering
* Standardized data for analysis

---

## Key Insights

* Manhattan has the highest average Airbnb prices
* Entire homes command premium pricing
* Most Airbnb listings fall within affordable price ranges
* Some neighborhoods consistently show premium pricing patterns
* High review counts do not always correlate with high listing prices
